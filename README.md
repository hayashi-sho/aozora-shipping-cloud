# AOZORA. Shipping Cloud v0.8（iPhone / MUNBYN）

v0.7のAmazon注文読込、クリックポストCSV、PDF変換、画像4面分割機能を維持。

## 内容品の自動入力
- マグネットローダー → マグネットローダー10枚セット
- ノズル・エアブロー → ノズルセット
- 18Vバッテリー関連 → 18vバッテリーラベル
- 40Vバッテリー関連 → 40vバッテリーラベル
- iPhoneガラス・保護フィルム → iPhoneフィルム

一致しない商品、複数種類の商品を含む注文は空欄として手動確認。内容品は編集可能です。すべて商品実物に合っているか確認してください。充電池本体などの対象外商品が混在する場合は、この品名を使用しないでください。

GitHub Pagesへの更新はindex.htmlをルートに上書きしてください。Amazon注文CSVや宛名データをGitHubに置かないでください。
