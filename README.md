# AOZORA. Shipping Cloud v0.5 – iPhone / MUNBYN ITPP130B

## GitHub Pages更新
既存リポジトリの `index.html` のみをこのバージョンに置き換えてください。購入者情報を含むCSVやラベル画像はGitHubにアップロードしないでください。

## 新機能
- 写真アプリやファイルからJPEG/PNGなど画像を読み込み
- A4 2列×2行のラベル画像を4枚の独立JPEGに変換
- 画像全体が1ラベルの場合も個別JPEGで保存
- 90/180/270度回転・外側余白の簡易調整
- 画像プレビュー・個別保存・長押しで写真に保存
- 旧注文CSV作成・MUNBYN向けPDF分割を維持

## 印刷方法
Chromeでクリックポストの正式ラベルを表示し、なるべく歪みのない画像で保存 → AOZORA画像分割 → プレビュー → JPEG保存 / 写真に保存 → Munbyn Printの画像印刷で1枚ずつ印刷。

## 制限
ブラウザはMUNBYNへ直接Bluetooth印刷できません。ページからiPhoneの「写真」に直接保存するAPIもないため、長押し保存または共有/ダウンロード操作が必要です。写真撮影された紙の傾き、台形歪みは自動補正しません。一般的なA4の均等4分割のみを対象にしています。実機・バーコード読取は未検証です。最初に1枚だけテスト印刷してください。
